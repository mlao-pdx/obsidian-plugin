# Appendix A: Design Decisions Considered and Rejected

## Appendix A: Design Decisions Considered and Rejected

Recorded so they are not relitigated.

| Decision                                                                                               | Rejected because                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hash tiebreaker in Clash Resolution                                                                    | Effectively random ordering — worse than surrendering visibly.                                                                                                                                                                                                                                                                   |
| Single `narrative_index` property                                                                      | NN rewrites `sort_index` unpredictably on drifted folder notes; two properties keep folder ordering immune.                                                                                                                                                                                                                      |
| Dataview inline syntax                                                                                 | Would pollute global Dataview queries and cede control of rendering.                                                                                                                                                                                                                                                             |
| `-` as context separator                                                                               | Keys are normalised against entity names that legitimately contain hyphens.                                                                                                                                                                                                                                                      |
| Nested inline properties                                                                               | A sentence serving four purposes would become unreadable. Multi-key `\|` solves it flatly.                                                                                                                                                                                                                                       |
| Field-type namespace (`setup__elara`)                                                                  | Inverts to `{Elara+setup=…}` under entity-first keys, which retires an entire subsystem.                                                                                                                                                                                                                                         |
| Subject-less properties (`{setup=…}`)                                                                  | If a thread is worth tracking it is worth a Plot note. Enforces Absolute Opt-In.                                                                                                                                                                                                                                                 |
| Making `◊` easy to type                                                                                | The namespace guarantee _is_ the inaccessibility.                                                                                                                                                                                                                                                                                |
| Wikilink-based setup→payoff pairing                                                                    | Unnecessary once the thread is an entity; anchor dispatch and heading-range scanning disappear with it.                                                                                                                                                                                                                          |
| Fractional ordinals for companion order                                                                | `companionRank` is a plain integer with no precision ceiling and nothing to re-derive.                                                                                                                                                                                                                                           |
| Minimum alias length guard                                                                             | Shared with the Mention Index, so a character named `Ed` would have had no progressions at all.                                                                                                                                                                                                                                  |
| `narradin_id` content sentinel for loop suppression                                                    | Renames carry no content; non-markdown files have no frontmatter; `vault.modify` races `metadataCache`.                                                                                                                                                                                                                          |
| Exclusive Narradin ownership of `aliases`                                                              | Would delete hand edits made in external editors.                                                                                                                                                                                                                                                                                |
| Note Properties readable from the body                                                                 | Canonical Index would depend on Content Projection to build the tree. Circular.                                                                                                                                                                                                                                                  |
| Per-Realm physical database separation                                                                 | Nested Realms put a row in two at once; Realm moves would force migrations.                                                                                                                                                                                                                                                      |
| Logical reattachment of out-of-order boundaries                                                        | Would require inventing a sort position the subtree does not physically have.                                                                                                                                                                                                                                                    |
| Global `ledgerWatermark`                                                                               | Incoherent once propagation was Local-Scope-bounded.                                                                                                                                                                                                                                                                             |
| Durable alias UUIDs                                                                                    | Nothing outlives propagation; array position suffices.                                                                                                                                                                                                                                                                           |
| Compile insert-at-cursor                                                                               | Editor lock-up on large compiles, and the output would be re-ingested and rewritten.                                                                                                                                                                                                                                             |
| Generated-file versioning and retention                                                                | That is git's job.                                                                                                                                                                                                                                                                                                               |
| `narradin__generated` as an overwrite precondition                                                     | Would create a second source of truth alongside `is`.                                                                                                                                                                                                                                                                            |
| Edit-distance entity matching in v1                                                                    | Would silently bind a property to the wrong entity.                                                                                                                                                                                                                                                                              |
| Judging POV shifts as errors                                                                           | Indistinguishable from omniscient narration. Count and report instead.                                                                                                                                                                                                                                                           |
| Usage/product analytics or telemetry of any kind                                                       | AGENTS.md is binding: no hidden telemetry, no data leaves the vault without explicit user action. Narradin will never collect or transmit usage statistics — see Decision Record B.16.                                                                                                                                           |
| A logging library (`tslog`, `LogLayer`)                                                                | `LogLayer` only facades other loggers, redundant with `LoggerPort`, which already exists for that seam; `tslog`'s value-add (pretty-printing, multi-transport) doesn't apply to a single plain-text vault file; neither ships an Obsidian-vault transport, so the adapter is hand-written regardless — see Decision Record B.16. |
| User-configurable narrative hierarchy                                                                  | Seesaw reconfiguration risked bulk reindexing and hierarchy-violation edge cases; fixed anchors with skippability give equivalent flexibility without the risk — see Decision Record B.17.                                                                                                                                       |
| Content-embedded self-write correlation token (`◊meaCulpa`)                                            | Solves nothing a properly idempotent check-then-act handler doesn't already solve; adds a permanent per-note frontmatter field, rotation-invariant bookkeeping, and doesn't cover non-markdown files or renames — see Decision Record B.18.                                                                                      |
| Timing-based self-write suppression (pending-write set with expiry, including the old-new rename pair) | The "infinite loop" it guarded against only occurs in an unconditional reactive handler; a handler that checks current state before acting converges without it — see Decision Record B.18.                                                                                                                                      |
| `pov`/`settings` as lozenge-prefixed System concepts                                                   | Neither is ever a valid `is` value; the frontmatter-only Note Property framing directly contradicted the inline lozenge form the spec itself showed in Part 16 — see Decision Record B.19.                                                                                                                                       |
| Git branching for edition management (print/ebook/audio)                                               | Companions (`__audio`, etc.) handle format divergence without forking manuscript history — see Decision Record B.20.                                                                                                                                                                                                             |
| Per-Realm Git repositories                                                                             | A single vault-wide repo also recovers accidental Narradin overreach into non-Narradin notes; Realm scope lives in the tag name instead — see Decision Record B.20.                                                                                                                                                              |
| Git remote and/or LFS configured by Narradin                                                           | This is local versioning, not backup; binaries are tracked directly — see Decision Record B.20.                                                                                                                                                                                                                                  |
| Leaving a partially-applied restore in place on failure                                                | An unknown partial state is worse than the original problem and complicates any retry — see Decision Record B.21.                                                                                                                                                                                                                |
| Automated status-floor version tags                                                                    | Late arrivals and status fallbacks make the "floor" unstable and would send false signals — see Decision Record B.22.                                                                                                                                                                                                            |
| Dedicated POV-change / Setting-change version tags                                                     | Too granular for a version event; already tracked as inline Entity Properties — see Decision Record B.22.                                                                                                                                                                                                                        |
| Omitting the `language` tag segment when it matches a default                                          | Tag meaning would silently shift if the vault's canonical-language default changes later — see Decision Record B.23.                                                                                                                                                                                                             |
| Fixed 5-anchor narrative hierarchy                                                                     | Caps depth/vocabulary that real narrative forms (screenplays, serials, poetry collections) don't share, and forces a dummy Series folder for standalone books — see B.17 (updated).                                                                                                                                              |
| Realm nesting severs (Island), matching every other anchor's order-violation treatment                 | Produces an inconsistent, "now I do, now I don't" UX between reporting and Compile — see B.2 (updated).                                                                                                                                                                                                                          |
| Bifurcated scope handling — reporting reaches across Realm boundaries, Compile does not                | Self-containment already comes from Local-Scope-bounded anchoring, which every operation already respects; a Realm-specific carve-out would be an unjustified special case with no corresponding problem to solve — see B.2 (updated).                                                                                           |
| Per-row `realmId` column (or a per-row list of realmIds) for blast-radius/orphan resolution            | Nested Realms break the mutual-exclusivity property the column depended on; an on-demand bounded ancestor walk is cheap enough (sub-millisecond, worst case) that no column-shaped fix is justified — see B.7/B.14 (updated).                                                                                                    |
| Boundary-node-level Realm-ancestry cache                                                               | Same premature-optimization reasoning as the row above — the on-demand walk is already cheap enough that no cache, at any granularity, earns its write-time/sync-risk cost — see B.7/B.14 (updated).                                                                                                                             |
| `◊status` severity-ranking (deciding which simultaneous concern is "worse")                            | Recency is a simpler, non-judgmental resolution rule consistent with Count and Report, Never Judge — see B.25.                                                                                                                                                                                                                   |
| Machine-owned status/health state represented as Obsidian tags                                         | Tags lack the lozenge namespace's deliberate typing friction, so machine-owned state would be trivially, accidentally disturbable — see B.25 / §9.0.                                                                                                                                                                             |
| `do_not_rename` as a bare boolean                                                                      | A timestamp value gives the author a handle on understanding what they're looking at; a bare presence/absence flag can't carry that — see B.24.                                                                                                                                                                                  |
