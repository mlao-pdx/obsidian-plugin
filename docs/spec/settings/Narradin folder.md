# Narradin folder

Narradin's internal notes and files, which are part of the vault, are stored in the Narradin folder, a location configured in Narradin's settings, by default set to `/_narradin`.

## Rationale

Logs, health reports, and hub notes need a place to live without poluting the user's vault. A dedicated directory for Narradin to write in, and the user to edit, should they want to, is the chosen solution. It is a common, well-worn pattern, and by suggesting the leading underscore ()`_`) instead of a period (`.`), it has a name that is easily hidden in [[Obsidian plugins#notebook-navigator]], while remaining visible to Obsidian.
