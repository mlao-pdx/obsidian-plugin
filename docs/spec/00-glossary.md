# Part 0: Glossary

## Part 0: Glossary

| Term                              | Meaning                                                                                                                                                                                                                                                                                                   |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Realm**                         | Top-level self-contained story world (Discworld, Cosmere). The only unskippable hierarchy level. Nothing exists to Narradin outside a Realm.                                                                                                                                                              |
| **Folder Note**                   | A note carrying a **folder-level** `is` value. The folder _containing_ it becomes a structural boundary.                                                                                                                                                                                                  |
| **Leaf Note**                     | A note carrying a **leaf-level** `is` value. Never a boundary, wherever it sits.                                                                                                                                                                                                                          |
| **Companion**                     | A note or file attached to a host Narrative note (`__prose`, `__beats`). A subsection of its host, with no independent narrative position.                                                                                                                                                                |
| **Generated Companion**           | A Companion written _by_ Narradin (compiler output). Excluded from indexing, replacement, and re-compilation.                                                                                                                                                                                             |
| **Host Group**                    | A Narrative note together with all its Companions. The unit across which positional values (POV, setting) resolve.                                                                                                                                                                                        |
| **Player**                        | A world entity: Character, Object, Lore, Location, Other.                                                                                                                                                                                                                                                 |
| **Plot**                          | A structural thread: Plot, Thread, Theme, Arc. Mechanically identical to a Player.                                                                                                                                                                                                                        |
| **Scope**                         | The bounding box a note operates in: which Narrative notes a command, report, query, or rewrite may see or touch. See Part 5 §5.5 for the full named taxonomy (Narradin, Narrative, Player, Plot, Companion, System, Realm, Local, Orphan, Indexed, Narrative Traversal, Compile, Reference-Valid Scope). |
| **Island**                        | A subtree severed from outer traversal by a hierarchy-order violation. Internally functional, externally invisible.                                                                                                                                                                                       |
| **Concept Note**                  | The note an `is` value links to (`[[A Story Realm]]`). Need not pre-exist; created on demand in `_narradin`.                                                                                                                                                                                              |
| **Source Note**                   | A note whose basename and aliases are tracked and propagated. Defaults to all Player and Plot `is` values.                                                                                                                                                                                                |
| **Note Property**                 | Frontmatter metadata whose subject is the note it sits in (`is`, `for`).                                                                                                                                                                                                                                  |
| **Inline Property**               | Umbrella term for the four brace constructs living in a note's body or frontmatter: Entity Property, Author Note, Internal Reference, and Editorial Property.                                                                                                                                             |
| **Entity Property**               | The default (unprefixed) Inline Property. Metadata whose subject is an entity named in its key. Frontmatter or body. Many per key per note.                                                                                                                                                               |
| **Author Note**                   | A `~`-prefixed Inline Property: a hidden note-to-self, never rendered outside source mode.                                                                                                                                                                                                                |
| **Internal Reference**            | A `!`-prefixed Inline Property: hidden bookkeeping (e.g. outtake pointers), invisible everywhere but source mode.                                                                                                                                                                                         |
| **Editorial Property**            | A `#`-prefixed Inline Property: a self-contained, threaded edit/comment/discussion with lozenge resolution markers.                                                                                                                                                                                       |
| **Position**                      | Per-Inline-Property tuple `(line, offset, blockId)`. A full cross-note sort key is composed at query time by joining this with the host note's `sequenceIndex`/`companionRank`.                                                                                                                           |
| **Content Sequence**              | The narrative sequence of a Narrative Traversal Scope (§5.5) with each note followed by its Companions. The single ordering primitive.                                                                                                                                                                    |
| **System Marker**                 | An Entity Property whose subject is a lozenge-prefixed System concept (`◊outtake`), or an Editorial Property resolution marker (`◊accepted`, `◊rejected`).                                                                                                                                                |
| **Configurable Key**              | A file-property key whose _name_ is user-definable, kept as an exchange layer with the author and other plugins (e.g. `is`, `sort_index`, `folder_index`, `icon`, `pov`, `setting`). See Part 9 §9.0.                                                                                                     |
| **Interpreted Key**               | The default case for a file-property key: neither Configurable nor System-prefixed, resolved as an Entity Property subject against Player/Plot entities. See Part 9 §9.0.                                                                                                                                 |
| **System Key**                    | A `◊`-prefixed file-property key, Narradin-authored and machine-owned, hidden by default. See Part 9 §9.0.                                                                                                                                                                                                |
| **Discriminator**                 | A non-role context. Used to distinguish threads within one entity when pairing setups and payoffs.                                                                                                                                                                                                        |
| **Release Tag**                   | An author-triggered git tag marking a handoff to an audience (Public/Editor/Agent/Publisher/Proof-reader). Bumps MAJOR (Public) or MINOR (closed audiences). See Part 17 §17.4.                                                                                                                           |
| **Progress Tag**                  | An author-triggered git tag marking a self-declared unit of completed work (prose/world-building/character-arc/plotting/marketing/errata + freeform detail). Bumps PATCH. See Part 17 §17.4.                                                                                                              |
| **NCA (Nearest Common Ancestor)** | In a version tag's scope segment, the narrowest confirmed node in the Realm/Series/Book/Act/Chapter/Leaf tree that covers everything the tag is about. See Part 17 §17.5.                                                                                                                                 |

**Terminology in user-facing text.** Every notice, modal, and report uses the author's
_configured_ concept names, never Narradin's internal ones. If Realm was renamed to
"Universe", the toast reads _"The 'Stormlight Archive' Universe's folder could not be
renamed…"_.
