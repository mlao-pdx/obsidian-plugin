# Part 11: Element Insertion

## Part 11: Element Insertion

Because Absolute Opt-In means a note without `is` does not exist, Narradin must make valid
notes trivial to create.

- An **Insert Element/Entity** command creates the appropriate note in the current location
  for a chosen concept.
- If a user template exists for that concept, use it. Otherwise generate a bare-bones
  template via **Templater** — minimal, but present, for the author to grow.
- Every generated note carries the correct `is` and an `icon` property (a Notebook
  Navigator link), so folders are visually legible at a glance.
- Companions are offered, never forced — no companion type is mandatory.
