# Roles

Notes that Narradin may read in full and perform actions are those notes that have a Narradin role assigned to their role property.

Narradin will listen for the Obsidian metadata events and read each note's frontmatter. If the frontmatter of a note has the Narradin [[Properties#Role property|role property]] and a valid value assigned to it, then Narradin will [[Indexing|index]] it.
