# Storyworld

A storyworld is a [[Scope boundary|scope boundary]] tied to the [[Roles|role]] of `◊storyworld`.

Storyworlds are the scope boundaries within which Narradin tries to resolve relationships. They may be nested, If this is the case, the nesting storyworld can look into the nested storyworld, but not the other way around.

This allows for creating a cross-over storyworld which can tie across two or more storyworlds, while each individual storyworld remains isolatd.
